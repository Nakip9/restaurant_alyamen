# مطعم اليمن السعيد

موقع عربي RTL مبني باستخدام Next.js App Router وReact وTypeScript وTailwind CSS وMotion. يُصدّر إلى ملفات ثابتة في `out` ويمكن استضافته دون خادم تطبيقات.

## التشغيل

```sh
npm ci
npm run dev
```

بناء نسخة الإنتاج ومعاينتها:

```sh
npm run build
node scripts/preview.mjs
```

المعاينة: http://localhost:3001 — صفحة فحص الأحجام المحلية: http://localhost:3001/__qa

## تعديل المحتوى

جميع بيانات المطعم والقائمة الأساسية موجودة في `src/data/restaurant.ts`. الألوان والمسافات والخطوط في `src/app/globals.css`. ملفات الصور في `public/images`. خط Tajawal مستضاف محليًا ضمن حزمة الموقع.

- الاسم والعنوان والهاتف والبريد الإلكتروني وخدمة السفري والتوصيل مستمدة من معلومات صاحب المشروع.
- لم يُمكن الوصول إلى فيسبوك للتحقق من الصور أو الشعار أو ساعات العمل أو القائمة الكاملة.
- المندي هو الصنف الوحيد المؤكد. الأسعار غير محددة، ولا توجد تقييمات أو ادعاءات جودة أو مكونات أو معلومات حساسية غير موثقة.
- الهوية الحالية معالجة تصميمية مقترحة للاسم، وليست إعادة إنتاج لشعار رسمي موثّق.
- صورة المندي مولدة بالذكاء الاصطناعي وموسومة بأنها تعبيرية، وتُستخدم في عدة اقتصاصات عرض CSS. استبدلها بصور المطعم المعتمدة قبل اعتماد المعرض كصور فعلية.
- نافذة الطلب تجهز ملخصًا قابلًا للنسخ وتفتح الاتصال الهاتفي. لا تُرسل الطلب تلقائيًا ولا تتضمن دفعًا أو حجزًا أو تكامل واتساب غير مؤكد.
- الخريطة بحث باسم المطعم والعنوان، وليست نقطة جغرافية موثقة. حدّث رابطها عند توفر رابط موقع رسمي.
- تُحذف أوقات العمل من البيانات المنظمة لعدم تأكيدها. يظهر بدلًا منها طلب الاتصال للاستفسار.
- عند ربط نطاق جديد، عيّن متغير البيئة `SITE_URL` ثم أعد البناء لتحديث canonical وOpen Graph وsitemap. يُكتشف عنوان الإنتاج تلقائيًا عند البناء على Vercel.

## التحقق

`npm run build` يتضمن تجميع الإنتاج وفحص TypeScript وتوليد الصفحات وrobots وsitemap. `npm run typecheck` متاح للفحص المستقل. تتضمن الواجهة بحثًا عربيًا، حالة نتائج فارغة، تصنيفات، نافذة طلب، تكبير صور، إغلاق Escape، حصر التركيز باستخدام dialog، وروابط اتصال وخرائط وبريد وفيسبوك. تحترم الحركة إعداد تقليل الحركة.

## الصورة التعبيرية

أُنشئت باستخدام أداة ImageGen المدمجة. الملفات النهائية: `public/images/mandi-hero.webp` و`mandi-detail.webp` و`mandi-table.webp`. الأصل محفوظ في `assets/mandi-source.png`. تفاصيل وصف التوليد في `assets/image-prompt.txt`.

## النشر

هذه نسخة مستقلة جاهزة للنشر على Vercel، دون ربط بحساب Sites أو تسجيل دخول ChatGPT. الإعدادات في `vercel.json`، وتعليمات الرفع في `DEPLOYMENT.md`. لا يحتوي المشروع على أسرار.

خطة Vercel Hobby المجانية مخصصة للاستخدام الشخصي غير التجاري، ولا تناسب الموقع التجاري للمطعم. لاستخدام Vercel تجاريًا اختر خطة مناسبة. تتوفر نسخة ثابتة جاهزة للرفع على Cloudflare Pages كخيار مجاني بديل، وفق حدود الخدمة وشروطها.

ارفع ملف المصدر `alyemen-alsaeed-vercel-ready.zip` إلى Vercel Drop. أما ملف `alyemen-alsaeed-static-upload.zip` فيحتوي على الموقع المبني، ويمكن رفعه مباشرة إلى Cloudflare Pages دون تثبيت أدوات تطوير. عند توفر عنوانك النهائي، عيّن `SITE_URL` وأعد البناء لاستكمال بيانات SEO الخاصة بالنطاق.
